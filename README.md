# GDDPro

Game design wiki + request tracker for AI agents (Windows desktop app).

This repository only hosts GDDPro's installers and update feed; the source code is private.

## Install

1. Download **[GDDPro-setup.exe](https://github.com/silentrebel123/GDDPro-releases/releases/latest/download/GDDPro-setup.exe)** (latest release).
2. Run it. It installs for your Windows user only, no admin rights needed.
   If Windows SmartScreen says "Windows protected your PC", choose **More info → Run anyway**.

## Updates

GDDPro checks this repository for a new version on start and every few hours, and offers
**Install and restart** in **Settings → App updates**. Every update is signed; GDDPro refuses
anything not signed with its release key.

All versions and release notes: [Releases](https://github.com/silentrebel123/GDDPro-releases/releases).
